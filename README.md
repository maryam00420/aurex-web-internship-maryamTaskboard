# React Task Manager — AUREX Month 2, Week 1

A component-driven Task Manager built with React.js and Vite for the AUREX Full-Stack Internship Month 2, Week 1 task.

## Features

- Add a new task using a controlled form input
- Display tasks dynamically using `map()`
- Mark tasks complete/incomplete
- Delete tasks from state
- Prevent empty task submission
- Reusable React component structure

## Component Structure

```text
App
├── Header
├── TaskForm
└── TaskList
    └── TaskItem
```

## React Concepts Used

- JSX
- Functional components
- Props
- `useState`
- Parent-child data flow
- Event handling
- Controlled form inputs
- List rendering with keys
- Basic validation
